# VictusFanControl v1.1.2 · Actualizaciones preliminares

Esta versión preliminar añade el canal de previews al actualizador integrado.

- En **Actualizaciones**, activa **Incluir versiones preliminares** y pulsa **Guardar** para conservar la preferencia. El canal estable sigue siendo el predeterminado.
- **Buscar actualizaciones** consulta las releases públicas de GitHub y ofrece la versión compatible más reciente del canal elegido, aunque el orden de publicación sea diferente. Las previews se identifican claramente.
- **Descargar e instalar** conserva la verificación de URL, tamaño y SHA-256, y libera la sesión de ventiladores y CPU/GPU antes de abrir el instalador. No instala versiones iguales o anteriores ni borradores.
- Cambiar o descartar el canal invalida el resultado anterior; una consulta pendiente no puede ofrecer una preview después de volver al canal estable.

Descarga **VictusFanControl-1.1.2-Setup-win-x64.exe**. La 1.1.1 tiene un actualizador de canal estable; para obtener esta primera versión con previews debes instalarla desde GitHub una vez. Después podrás actualizar desde el programa con la opción activada.

Conserva las mejoras de Protecciones y recuperación de la 1.1.1. Las preferencias se mantienen al actualizar. Sigue dirigido al HP Victus 8C40 / 9D0R1LA / BIOS F.18, con los mismos requisitos PawnIO/NVIDIA. Pruebas de software sin E/S de hardware; no se afirma una nueva validación física del portátil.
