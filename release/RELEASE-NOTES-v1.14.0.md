# VictusFanControl 1.14.0 preliminar

- Automático conserva su intención de reanudación al descartar o restaurar la preferencia. La recuperación vuelve a comprobar el estado de Windows inmediatamente antes de abrir el recuperador. Una liberación de CPU/GPU incierta conserva su bloqueo y registra ambos errores.
- El actualizador puede confirmar una lectura WMI que terminó tarde. Instalar y reiniciar protegen los borradores de HyperX y de la base externa. El instalador incluye un asistente de Windows que conserva los perfiles y el registro de inicio existente.
- El enfriamiento previo al apagado usa una sola lectura de corriente para la admisión. Mantiene su duración máxima y los controles de seguridad existentes.
- El inicio con Windows usa la opción de minimizar guardada. Si Windows rechaza el cambio, la aplicación indica que los perfiles se guardaron y permite reintentar.
- Un fallo al escribir los ajustes de la base externa mantiene la conexión anterior. Al guardar una curva, la interfaz distingue el archivo guardado de la confirmación del ESP32.
- HyperX recupera la lectura tras una consulta nueva válida si se perdió el aviso de encendido. El primer estado activo después de una reconexión ya no genera un aviso falso de micrófono activado. La alerta baja sigue funcionando al desactivar la crítica y los umbrales altos se rearman al recargar. El PC admite una referencia local de voltaje para el 100 %.
- La exportación conserva las líneas completas en el límite de tamaño. Las correcciones de alertas del LCD están en el código del ESP32 y requieren su propio despliegue al dispositivo.
